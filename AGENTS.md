# Q Comet agent instructions

The active product is `qcomet`, public name **Q Comet**, manufacturer **Q Motors**.

## Non-negotiable rules

- Preserve an original fictional identity. Do not reproduce or import geometry, badges, textures, sounds, handling, or code from real vehicles or other games.
- Treat all dimensions in `project.json` as provisional until Quasar approves a dimension sheet.
- Do not fabricate binary GTA assets. `.yft`, `.ytd`, `.ybn`, and related outputs must come from the reviewed Blender/Sollumz workflow.
- Keep body panels, glass, lights, wheels, collision, and interior components separable.
- Use the game-oriented cabin reference for v1. The cinematic dashboard is inspiration only.
- Maintain four usable seats and clean first-person visibility.
- Never claim NoPixel affiliation, approval, or direct player installation.
- Do not publish or sell until a human completes the test checklist.

## Naming

- Resource/spawn name: `qcomet`
- Blender source: `qcomet_<stage>_vNNN.blend`
- Textures: `qcomet_<area>_<map>_<resolution>`
- Use lowercase ASCII identifiers for game files.

## Definition of a finished v1

Four functional doors, hood, trunk, wheels and steering, four seats, paint and glass, complete lights, interior, collision, sensible LODs, valid metadata, clean-server spawn test, performance evidence, installation guide, listing media, and provenance records.
