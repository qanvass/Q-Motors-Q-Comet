# Q Comet concept sources

These images are visual references, not geometry or production-ready textures.

## Primary sheets

- `q comet all four sides.png`: front, rear, left, and right exterior views
- `q comet front rear top.png`: top and three-quarter exterior views
- `Q Comet Front view showroom.png`: hero/material reference
- `q comet wheel headlight tail light on and off.png`: wheel and lighting reference
- `q comet cabin dash.png`: primary game-oriented cabin
- `q comet dash board.png`: cinematic interior inspiration only

`q comet cabin view and driver view.png` is byte-identical to the primary cabin sheet and is intentionally not copied into this working set.
